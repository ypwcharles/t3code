## Rollback / Risk

官方 [V1→V2 说明](https://github.com/pingdotgg/t3code/issues/14871)：V2 使用一次性复制，
之后 V1/V2 数据各自演进；旧 provider live session、reasoning、检查点、工具活动、
审批历史与 proposed plans 不进入 V2 时间线。旧会话首次继续会建立新 provider session。

V1 桌面与手机无法连接 V2。Mac 定制 `0.0.45` 本次未改，需另行迁移翻译与 SSH 修复后
升级；手机需 T3 Code 2.0。没有发起付费模型请求，也没有宣称桌面/手机端到端验收通过。

最小配置备份：
`/var/backups/hermes-agent/20261017T160230Z-t3code-0.1.0`，8994 bytes，root-only。
包括 unit、settings、keybindings、路径/版本 manifest，不含数据库或凭据副本；
有 `.hermes-config-backup` 标记，保留 14 天，至 2026-11-01 00:02 SGT。
旧 `0.0.45` runtime 原位保留，没有创建额外程序或数据库备份。

如需回退程序，使用同一 OCI 专用 SSH 入口，在远端执行：

```sh
/home/ubuntu/.local/bin/t3 update 0.0.45 --allow-downgrade --yes
/home/ubuntu/.local/bin/t3 --version
```
